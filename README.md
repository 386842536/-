    <h1>像素画应用隐私政策</h1>
    
    <h2>引言</h2>
    <p>像素画应用（以下简称"本应用"）致力于保护用户隐私。本政策详细说明了本应用如何收集、使用和保护用户信息。</p>
    
    <h2>数据收集</h2>
    <p>本应用是一款单机应用，所有数据处理都在本地完成，不会向服务器发送任何用户数据。</p>
    
    <h3>收集的信息</h3>
    <p>1. <strong>本地存储数据</strong>：</p>
    <ul>
        <li>应用设置（如网格大小、颜色数量等）</li>
        <li>颜色覆盖设置</li>
        <li>处理过程中的临时数据</li>
    </ul>
    
    <p>2. <strong>权限使用</strong>：</p>
    <ul>
        <li>相册访问权限：用于上传图片和保存导出的作品</li>
        <li>文件系统访问权限：用于保存和管理导出的作品</li>
    </ul>
    
    <h2>数据使用</h2>
    <p>本应用收集的信息仅用于以下目的：</p>
    <ul>
        <li>提供和改进应用功能</li>
        <li>保存用户设置和偏好</li>
        <li>实现图片处理和导出功能</li>
    </ul>
    
    <h2>数据存储</h2>
    <p>所有数据均存储在用户设备本地，不会上传到任何服务器。用户可以通过删除应用来清除所有本地存储的数据。</p>
    
    <h2>第三方服务</h2>
    <p>本应用不使用任何第三方服务，不会与任何第三方共享用户数据。</p>
    
    <h2>儿童隐私</h2>
    <p>本应用适合所有年龄段的用户使用，不会收集任何儿童个人信息。</p>
    
    <h2>隐私政策更新</h2>
    <p>本隐私政策可能会不时更新，更新后的政策将在应用中公布。</p>
    
    <h2>联系我们</h2>
    <p>如果您对本隐私政策有任何疑问，请联系我们。</p>
